# 🏗️ Projetos & Operação: A Fábrica de Entregas

Este módulo é o coração da produção do HubCRM, onde as vendas se transformam em resultados concretos para o cliente. É aqui que os gestores operacionais monitoram a saúde das entregas e garantem que os prazos (SLAs) sejam cumpridos.

## 🚦 O Semáforo de Produção

Os projetos são organizados em três estados críticos para facilitar a priorização:
- **Em Execução**: Projetos que estão dentro do prazo e em produção ativa.
- **Críticos / SLA**: Projetos que excederam o tempo limite de entrega (SLA padrão de 20 dias em desenvolvimento). Estes aparecem com alertas visuais e pulsação em vermelho.
- **Entregues**: Histórico de projetos finalizados que já se tornaram clientes ativos.

---

## 📊 Acompanhamento de Progresso

Cada projeto possui uma barra de progresso automática:
- **Cálculo por Estágios**: O percentual de conclusão é calculado dividindo o número de etapas concluídas pelo total de etapas do projeto.
- **Próximo Passo**: O sistema exibe sempre qual é a próxima ação pendente para que a equipe não perca o foco.

---

## 👥 Gestão de Responsabilidade

No HubCRM, cada projeto tem um "Dono":
- **Atribuição**: Vincule um membro da equipe a cada projeto.
- **Rastrabilidade**: Saiba exatamente quem é o responsável por cada entrega e qual o volume de carga de trabalho de cada colaborador.

---

## 🛠️ Como Gerenciar um Projeto

1. Acesse a aba de **Projetos**.
2. Clique em **Gerenciar Projeto** no card desejado.
3. Você será levado à tela de detalhamento do cliente, onde poderá:
   - Marcar etapas como concluídas.
   - Adicionar logs de atividade.
   - Alterar o responsável técnico.
   - Subir arquivos e documentações.

---

## 💡 Dicas de Especialista

> [!TIP]
> **Checklist de Qualidade.** Antes de marcar a última etapa como concluída e mover o cliente para "Ativo", use a Wiki interna para conferir se todos os critérios de qualidade da sua empresa foram atingidos.

> [!IMPORTANT]
> **O Alerta de SLA não é punitivo, é preventivo.** Se um projeto entrar na aba "Críticos", verifique se houve falta de dados do cliente ou se a equipe precisa de reforço. O sistema avisa antes que o cliente reclame.

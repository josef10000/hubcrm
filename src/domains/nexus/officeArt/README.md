# Habblaud character renderer

The procedural pixel-art character renderer in `art/` is adapted from Habblaud by Márcio Junior: https://github.com/marmottajr/habblaud

Source revision: `faa1a012b5fbf632c66dc6801c5383e53a542406`.

Habblaud is distributed under the MIT License; the full notice is in `LICENSE-HABBLAUD.txt`. The Hub wrapper and its appearance palettes are original integration code. The renderer runs locally in the browser and creates each avatar from code; no external character sprites or network requests are used.

Characters use different seeded skin tones, hairstyles, accessories, outfits, and facial expressions. The Hub selects standing, typing, walking, and hand-raising poses to reflect simulated activity.

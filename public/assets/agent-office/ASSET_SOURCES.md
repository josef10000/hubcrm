# Fontes dos elementos visuais

- Móveis, pisos, carpetes e paredes foram adaptados dos arquivos distribuídos com Pixel Agents, de Pablo De Lucca. Repositório: https://github.com/pixel-agents-hq/pixel-agents
- Revisão de origem usada na cópia: `4dd14d6`.
- O código e os elementos visuais incluídos do Pixel Agents estão sob MIT. A licença integral está em `PIXEL_AGENTS_LICENSE.txt`.
- Personagens e interface desta sala foram feitos para o Hub Central. Não foram copiados sprites proprietários do Gather Town.
- Personagens pixel art são renderizados proceduralmente com o módulo de arte do Habblaud, de Márcio Junior: https://github.com/marmottajr/habblaud, revisão `faa1a012b5fbf632c66dc6801c5383e53a542406`, licença MIT. Implementação e crédito em `src/domains/nexus/officeArt/`.
- O repositório Habblaud é usado apenas como origem do renderizador de personagens. Nenhuma cena, sala ou sprite proprietário do Gather Town foi copiado.
